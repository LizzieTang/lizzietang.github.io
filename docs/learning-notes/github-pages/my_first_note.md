# Github Pages Intro

## First Github Page in 2 mins
1. Login to your GitHub Account
2. Create a new repo, name it as '<your-github-account-name>.github.io'
3. Go to the newly created repo
4. Create a new file, name it as 'index.html'
5. Put simple HTML code in the newly created file.
6. Access this address in your browser: https://<your-github-account-name>.github.io
7. Done
